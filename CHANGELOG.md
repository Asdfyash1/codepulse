# Changelog

All notable changes to CodePulse will be documented in this file.

## [1.0.0] - 2025-04-29

### Added
- Beautiful CLI codebase analyzer with Rich terminal output
- Language detection for 40+ programming languages
- Lines of code counting (code, comments, blanks)
- Visual bar charts and directory size breakdown
- JSON export for CI/CD integration
- AI-powered code insights (health score, architecture review, improvements)
- AI code review for individual files
- Multi-provider AI support: OpenAI, Google Gemini, NVIDIA
- Automatic API key detection with fallback chain
- Comprehensive test suite (5 tests)
- GitHub Actions CI with Python 3.9-3.12 matrix
